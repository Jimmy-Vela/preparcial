Descripción del proyecto

Registro de caja es un programa desarrollado en Google colab para controlar el recaudo de dinero de una caja durante un turno. El programa permite registrar y administrar las transacciones de los clientes mediante un CRUD, controlar el tope máximo de recaudo y suspender la caja cuando este se alcanza o se supera. También permite guardar y leer la información mediante archivos CSV y genera un reporte final con los datos principales del turno.
